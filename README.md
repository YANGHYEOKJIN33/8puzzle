# 8-퍼즐로 배우는 인공지능 탐색 알고리즘

파이썬을 잘 몰라도 **8-퍼즐**을 소재로 인공지능 기초 교과서의 탐색 알고리즘을
**순서도 → 의사코드 → 파이썬 코드** 순서로 배울 수 있는 웹 학습 사이트입니다.

코드가 한 줄 실행될 때마다 **OPEN·CLOSED 같은 자료구조가 어떻게 변하는지**를
눈으로 보고 직접 조작하며 익히는 것이 이 프로젝트의 핵심입니다.

---

## 무엇을 배우나요

**맹목적 탐색** — 너비 우선(BFS), 깊이 우선(DFS), 깊이 제한(DLS), 반복적 깊이 심화(IDS)
**경험적 탐색** — 언덕 등반(Hill Climbing), 최상 우선(Best-First), A\*

같은 문제를 서로 다른 알고리즘으로 풀어 보며,
**"OPEN이 큐인가 스택인가 우선순위 큐인가"** 하나가 알고리즘의 성격을 어떻게 바꾸는지 확인합니다.

## 탭 두 개 — 자료구조 먼저, 그다음 탐색

맨 위에 탭이 두 개 있습니다. 스택·큐를 배운 적 없는 학생을 위해
**📦 자료구조 탭이 첫 화면**입니다.

### 📦 자료구조 (5쪽) — 첫 화면

큐·스택·우선순위 큐를 **직접 넣고 꺼내 보며** 규칙 하나씩 익힙니다.
화면은 왼쪽에서 오른쪽으로 흐릅니다 — **넣은 순서 → [구조] → 나온 순서**.
가운데 그림은 생김새가 곧 규칙입니다.

| 구조 | 생김새 | 규칙 |
|---|---|---|
| 큐 | 양 끝이 뚫린 **가로 관** | 왼쪽으로 들어와 오른쪽으로 나간다 |
| 스택 | 위만 뚫린 **세로 통** | 넣는 곳과 꺼내는 곳이 같아서 순서가 뒤집힌다 |
| 우선순위 큐 | **새치기가 되는 관** | 번호가 작을수록 급해서 앞으로 끼어든다 |


1. 큐 — 줄 서기(매표소 줄) · 2. 스택 — 접시 쌓기 · 3. 우선순위 큐 — 응급실
4. 셋을 나란히 견줘 봐요 — 같은 것을 같은 순서로 넣어도 나오는 순서가 다르다
5. 자료구조가 곧 탐색 방법이에요 — 큐→BFS, 스택→DFS, 우선순위 큐→최상 우선·A\*

쪽마다 **“다음에 꺼내면 무엇이 나올까요?” 맞히기**가 있어, 규칙을 스스로 확인합니다.
5쪽에서 [이 탐색 보러 가기]를 누르면 그 자료구조로 도는 8-퍼즐 탐색으로 바로 넘어갑니다.

### 🧩 8-퍼즐 탐색 (7쪽)

한 화면에 배울 것 하나만 담고 [다음 →] 으로 넘어갑니다. 쪽마다
**📘 배울 것**과 **✋ 해 볼 것**이 적혀 있어, 무엇을 배우는지 분명합니다.
(두 탭 모두 같은 진행 막대를 씁니다.)

1. 이 퍼즐이 뭐예요? · 2. 컴퓨터는 하나씩 살펴봐요 · 3. 대기 목록이 뭐예요?
4. 줄 세우는 방법을 바꿔 봐요(대기 목록과 나무를 한 화면에서 비교)
5. 순서도와 코드로 봐요(옆에 퍼즐 판) · 6. 빈칸을 채워 봐요 · 7. 직접 만들어 봐요

## 용어는 정확하게, 설명은 쉽게

화면에는 **교과서와 같은 정확한 용어**를 씁니다(노드 · 상태 · 확장 · OPEN 리스트 ·
CLOSED · 탐색 트리 · 휴리스틱). 대신 바로 옆에 쉬운 말을 붙여 뜻이 막히지 않게 합니다.

- 동작 카드: **확장** `expand` — "지금 노드에서 갈 수 있는 자식 노드들을 만들어요"
- 카운터: **생성 노드** · 만든 배치 / **확장 노드** · 살펴본 배치
- 위쪽 **📖 용어** 단추를 누르면 41개 용어를 찾아볼 수 있는 사전이 열립니다.

휴리스틱은 알고리즘마다 가장 기본인 것으로 자동 선택되어, 학생이 고를 필요가 없습니다.
**⚖ 비교** 화면에는 이번 문제에서 잰 값뿐 아니라
**완전성 · 최적성 · 시간 · 공간** 같은 교과서 성질표도 함께 실려 있습니다.

## 예전 구성 — 3단계 학습

| 단계 | 학생이 하는 일 | 목표 |
|---|---|---|
| **1단계 · 의사코드** | 버튼만 누른다. 코드 작성 없음 | 알고리즘의 흐름과 자료구조 변화를 눈으로 익힌다 |
| **2단계 · 빈칸 채우기** | 파이썬 코드의 핵심 부분만 채운다 | 코드 한 곳이 알고리즘을 바꾸는 것을 체험한다 |
| **3단계 · 직접 작성** | 빈 편집기에 직접 작성한다 | 스스로 탐색 알고리즘을 구현한다 |

**2단계에서 만든 것** — 화면 배치(코드 / 퍼즐 판 / 자료구조 3분할), 알고리즘 7종 선택,
학습 단계 1·2·3 전환, 순서도·의사코드·파이썬 탭, 실행 제어 막대와 키보드 단축키,
다크 모드, 글자 크기 조절, 설정 자동 저장, GitHub Pages 자동 배포.

**3단계에서 만든 것** — 화면을 전혀 모르는 순수 로직(`src/core/`)으로
8-퍼즐 규칙(`puzzle.js`)과 휴리스틱 3종(`heuristics.js`)을 구현하고 테스트로 검증했다.

**4단계에서 만든 것** — 탐색 한 걸음마다 무슨 일이 있었는지를 남기는 단계 기록기
(`trace.js`)와 그 위에 올린 너비 우선·깊이 우선 탐색(`algorithms/`). 기록은
OPEN 전체를 복사하지 않고 델타(들고 남)만 담아 되감기와 성능을 함께 얻는다.

**5단계에서 만든 것** — 단계 기록을 실제로 눈에 보이게 했다. 재생기(`player.js`)가
장면을 한 컷씩 넘겨 주면, 퍼즐 판이 검사 중인 배치를 따라 움직이고, 의사코드의
현재 줄이 강조되며, OPEN이 큐/스택 모양의 가로 띠로 노드가 들고 나는 모습을 보여 준다.
▶ 재생 · ⏭ 한 단계 · ⏮ 뒤로 · ⏹ 처음으로 · ⏩ 해까지와 키보드 단축키가 모두 동작한다.
재생기 로직까지 포함해 테스트 61개로 검증했다.

**6단계에서 만든 것** — 세 가지 표현 중 순서도(`flowchart.js`)를 인라인 SVG로 그려
실행 중인 도형을 강조하고(요구사항 3.3.1), 학습 1단계에 예측 퀴즈(`coach.js`)를 더했다.
"다음에 꺼낼 노드는?"을 물어 학생이 큐/스택의 성격을 스스로 떠올리게 한다(요구사항 5.1.2).

**7단계에서 만든 것** — 나머지 다섯 알고리즘을 더해 7종이 모두 동작한다.
A\*(f=g+h)·최상 우선(h)은 OPEN을 평가값 순으로 정렬한 우선순위 큐로 보여 주고,
언덕 등반은 이웃 후보와 지역 최적에 막히는 모습을, 깊이 제한·반복적 깊이 심화는
깊이 한계의 필요성을 보여 준다. 휴리스틱(h0·h1·h2)을 골라 A\*가 어떻게 달라지는지
비교할 수 있다. A\*·IDS가 최단 해를 냄을 참값과 대조해 검증했다(테스트 70개).

**8단계에서 만든 것** — 학습 2단계(빈칸 채우기). 거의 완성된 파이썬 코드에서
`OPEN.pop(___)` 같은 핵심 한 곳만 드롭다운으로 채우면, `0`은 너비 우선, `-1`은
깊이 우선이 되는 것을 직접 확인한다. 정렬 기준(`n.h` vs `n.g+n.h`)으로 최상 우선과
A\*를, 휴리스틱 정의로 A\*가 얼마나 적게 펼치는지를 비교한다. 채우면 그 코드로 실제
탐색을 돌려 옆에서 시각화하고, "무엇이 달라졌는지"를 결과로 보여 준다(요구사항 5.2).

**9단계에서 만든 것** — 학습 3단계(직접 작성). 학생이 파이썬 `search()`를 편집기에
직접 쓰고, **Pyodide로 브라우저에서 진짜 파이썬을 실행**한다(3단계에 처음 들어올 때만
지연 로딩 · 요구사항 7.2.1). 돌려준 경로를 규칙에 맞는지 검사한 뒤 퍼즐 판에서
재생하고, 오류는 한국어로 친절히 설명한다(요구사항 5.3.3). 코드는 브라우저에
자동 저장되고(5.3.6), 한 번 실행하면 정답 보기가 열린다(5.3.5).

**이로써 세 학습 단계(의사코드 → 빈칸 채우기 → 직접 작성)가 모두 완성**되었다.

**10단계에서 만든 것** — 알고리즘 비교 화면(요구사항 3.2.3). 상단 ⚖ 비교 버튼을 누르면
같은 초기 상태로 7가지 알고리즘을 돌려 해 길이·펼친 노드·OPEN 최대·단계 수를 표로
나란히 보여 준다. 열별 최고값을 초록으로 표시하고, 행을 누르면 그 알고리즘으로 화면을
바꾼다. 무거운 계산이 화면을 멈추지 않도록 한 알고리즘씩 나눠 실행한다.

**학습자 이해 개선(동적 시각화)** — 정적인 화면을 움직이게 다듬었다.
- 퍼즐 타일이 빈칸으로 **미끄러져 들어가는** 애니메이션(어떤 이동인지 눈으로 따라감)
- OPEN에 새 노드가 **톡 튀어 들어오고**, 검사 중인 노드가 한 번 맥동, 해설이 부드럽게 바뀜
- **첫 방문 3단계 안내**(요구사항 6.1.6) — 문서 대신 말풍선으로 화면 사용법을 알려 주고,
  ? 도움말 버튼으로 다시 볼 수 있음
- 모바일 가로 넘침 정리. 7종 알고리즘 × 3단계 × 비교를 훑어 콘솔 오류가 없음을 확인

**11단계에서 만든 것(마무리)** — 접근성 점검(모든 버튼에 이름·라벨, 키보드 조작,
초점 표시), 다크 모드·모바일 확인, 자료구조 패널 탭 전환이 즉시 반영되도록 수정,
그리고 [교사용 안내(docs/TEACHER.md)](./docs/TEACHER.md)를 추가했다.

**→ 계획한 11단계를 모두 마쳤습니다.** 학생은 주소 하나로 접속해 7종 탐색을
순서도·의사코드·파이썬으로, 세 학습 단계로 배우고, 자료구조를 바꿔가며 OPEN과
탐색 트리가 함께 변하는 모습을 관찰할 수 있습니다.

## 기술 방향

빌드 도구 없이, 브라우저가 그대로 읽는 HTML + CSS + ES 모듈로 만든 정적 사이트입니다.
1·2단계는 즉시 실행되는 JavaScript 시뮬레이터로, 3단계는 브라우저에서 진짜 파이썬을 실행하는
**Pyodide** 로 동작합니다. 학생은 설치도 로그인도 없이 주소 하나로 접속합니다.
