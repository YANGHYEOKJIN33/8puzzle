# 교사용 안내 — 8-퍼즐로 배우는 탐색 알고리즘

이 사이트는 파이썬을 잘 모르는 **고등학생**이 인공지능 기초의 **탐색 알고리즘**을
자료구조 → 개념 → 알고리즘별 동작 → 순서도·의사코드 → 파이썬 순서로 배우도록 만든 것입니다.
설치·로그인 없이 주소 하나로 접속하며, **이 페이지 하나로 여러 차시 수업**을 진행할 수 있습니다.

> 사이트 주소: `https://yanghyeokjin33.github.io/Alg/`

---

## 1. 화면 구조 — 큰 탭 넷(2단계 내비게이션)

맨 위에 큰 탭이 넷 있습니다. 왼쪽에서 오른쪽으로 수업 순서이기도 합니다.

| 큰 탭 | 쪽 수 | 무엇을 |
|---|---|---|
| **📦 자료구조** | 5쪽 | 큐·스택·우선순위 큐를 손으로 넣고 꺼내며 익힌다(첫 화면) |
| **🧩 탐색 기초** | 7쪽 | 8-퍼즐·상태·노드·확장·OPEN·CLOSED·순서도·휴리스틱 |
| **🌿 알고리즘** | 5개 × 4쪽 | 알고리즘마다 **하위 탭**으로 하나씩 깊게 |
| **✅ 정리·확인** | 2쪽 | 배운 것 정리 + 이해 확인 문제 |

**🌿 알고리즘 탭**에는 알고리즘 하위 탭이 있습니다:
`[너비 BFS] [깊이 DFS] [최상우선] [A*] [언덕등반]`. 하위 탭 하나가 알고리즘 하나이고,
**각 알고리즘은 똑같은 4쪽**으로 배웁니다.

> ① **어떻게 8퍼즐을 푸나** — 실제로 돌려 보며 트리·OPEN·CLOSED로 성격을 관찰(동적)
> ② **의사코드 읽기** — 각 줄이 하는 일과 이유를 한 줄씩
> ③ **줄별 동작을 이미지로** — 밟을 때마다 그 줄이 바꾸는 판·OPEN·CLOSED가 함께 움직인다
> ④ **의사코드 ↔ 파이썬** — 같은 줄을 나란히 놓고, 핵심 한 줄을 바꿔 차이를 관찰

④쪽 하단 "🔑 핵심 한 줄 바꿔 보기"에서 **꺼내는 자리(pop) 또는 정렬 기준 한 줄**만 바꾸면
알고리즘이 통째로 달라지는 것을 눈으로 확인합니다(BFS↔DFS, 최상우선↔A*).

깊이 제한(DLS)·반복적 깊이 심화(IDS)는 본 수업에서 다루지 않고 **⚖ 비교** 화면에만 둡니다.

## 2. 차시 예시

한 쪽에 배울 것 하나만 담고, "📘 배울 것"(왜 배우는지 이유까지)과 "✋ 해 볼 것"이 적혀 있습니다.
한 화면에는 그 쪽에 꼭 필요한 것만 켜지고, 자료구조와 탐색 트리처럼 둘을 견줄 때는
**[자료구조 | 탐색 트리] 탭**으로 하나씩 봅니다.

### 1차시 — 준비: 자료구조 (📦 자료구조)

스택·큐를 배운 적 없는 학급을 위한 준비 차시입니다(이미 배운 학급은 건너뜁니다).

| 시간 | 쪽 | 내용 |
|---|---|---|
| 0~10분 | 1. 큐 | 매표소 줄 비유 → 넣기·꺼내기를 직접 눌러 본다(FIFO) |
| 10~18분 | 2. 스택 | 접시 더미 비유 → 같은 것을 넣어도 순서가 뒤집힌다(LIFO) |
| 18~26분 | 3. 우선순위 큐 | 응급실 비유 → 나중에 와도 급하면 앞으로 |
| 26~35분 | 4. 셋을 나란히 | 같은 입력, 다른 출력. "상자가 순서를 정한다" |
| 35~45분 | 5. 잇기 | [이 탐색 보러 가기]로 알고리즘 탭으로 넘어간다 |

### 2차시 — 탐색 기초 (🧩 탐색 기초, 7쪽)

| 시간 | 쪽 | 내용 |
|---|---|---|
| 0~7분 | 1. 8-퍼즐과 상태 | **타일을 직접 밀어** 상태·연산자를 손으로 |
| 7~14분 | 2. 상태공간과 탐색 | 이웃 상태가 그물처럼 이어짐 → 왜 탐색이 필요한가 |
| 14~22분 | 3. 노드와 확장 | ⏭ 로 노드를 확장해 자식이 생기는 것 |
| 22~29분 | 4. OPEN | 자식이 생길 때 늘고(push), 꺼낼 때 주는(pop) 것 |
| 29~36분 | 5. CLOSED | 꺼낸 노드가 CLOSED에 쌓이는 것(무한 반복 방지) |
| 36~41분 | 6. 순서도 | 판단 두 개·되돌이 화살표가 **왜 이 모양인지** |
| 41~45분 | 7. 휴리스틱·평가함수 | 지금 배치의 h₀·h₁·h₂ 값과 f = g + h |

### 3~4차시 — 알고리즘별 심화 (🌿 알고리즘)

알고리즘 하위 탭을 하나씩, 각 4쪽으로 진행합니다. 한 알고리즘에 약 12~18분.
**맹목적(너비·깊이) → 경험적(최상·A*) → 국소(언덕등반)** 순서를 권합니다.

| 하위 탭 | ①동작에서 발견할 것 | ④핵심 한 줄 |
|---|---|---|
| 너비 BFS | 트리가 층층이 넓게 → 최단, OPEN이 크게 부푼다 | `OPEN.pop(0)` |
| 깊이 DFS | 한 줄로 깊게 → 헤맨다, 메모리는 적다 | `OPEN.pop(-1)` |
| 최상우선 | h가 작은 것부터 → 빠르지만 최단은 아님 | `key = x.h` |
| A* | f = g + h → 빠르면서 최단 | `key = x.g + x.h` |
| 언덕등반 | 이웃만 보고 오르다 지역 최적에 막힘 | — |

각 알고리즘에서 ①로 동작을 보고 → ②로 의사코드를 읽고 → ③으로 줄마다의 변화를 보고 →
④로 파이썬과 맞춰 본 뒤, 다음 하위 탭으로 넘어갑니다. **[탐색 트리] 탭**으로 알고리즘마다
트리 모양이 어떻게 다른지 견주게 하면 차이가 한눈에 보입니다.

### 마무리 — 정리·확인 (✅ 정리·확인)

"자료구조 → 알고리즘" 표로 되짚고(표의 줄을 누르면 그 알고리즘 탭으로 이동), **이해 확인**
문제 5개로 마칩니다. 답을 고르면 바로 정답과 이유가 나오고, 맞힌 개수가 표시됩니다.

## 3. 화면 구성 한눈에

- **한 화면 = 한 개념**: 그 쪽에 필요한 패널만 켜집니다. 순서도(기초 6쪽)와 의사코드(알고리즘 ②)는
  나란히 쌓지 않고 각각 다른 쪽에 둡니다.
- **퍼즐 판**: 검사 중인 배치와 목표 배치를 나란히. 밀린 타일이 미끄러지며 강조됩니다.
- **[자료구조 | 탐색 트리] 탭**: 알고리즘 ①쪽에서 자료구조 패널 위에 있어, OPEN·CLOSED와
  탐색 트리를 **한 번에 하나만** 봅니다(기본=자료구조).
- **OPEN(대기 목록)**: 자료구조 탭과 같은 관/통 그림 — 큐·우선순위 큐는 가로 관(왼쪽 push,
  오른쪽 pop), 스택은 오른쪽 한 곳(왼쪽은 막힌 바닥). 오른쪽 끝(다음)은 파랑, 방금 넣은 것은 초록.
- **CLOSED(닫힌 목록)**: OPEN 아래 상자에 꺼낸 노드가 쌓입니다. 방금 옮겨 온 노드는 주황.
- **줄별 동작(알고리즘 ③)**: 왼쪽 의사코드 줄이 켜지는 순간 오른쪽 판·OPEN·CLOSED가 함께 움직여
  "코드 한 줄 = 화면의 어떤 변화"를 잇습니다.
- **의사코드↔파이썬(알고리즘 ④)**: 같은 줄을 나란히, 밟으면 양쪽이 함께 켜집니다. 파이썬을
  몰라도 원리가 보이도록 했습니다. 핵심 한 줄만 바꿔 알고리즘이 달라지는 것을 실험합니다.
- **휴리스틱(기초 7쪽)**: 지금 배치의 h₀·h₁·h₂ 값과 f = g + h를 실제 숫자로 보여 줍니다.
- **동작 카드**: 지금 하는 일을 그림 + 한 문장(꺼내기 👆 / 넣기 📥 / 찾았다 🎉 …)으로.
- **예측 퀴즈**: OPEN이 둘 이상일 때 "다음에 꺼낼 노드는?"이 떠, FIFO/LIFO를 스스로 떠올리게 합니다.
- **위 — 실행 제어**: ▶ 재생 / ⏭ 한 단계 / ⏮ 뒤로 / ⏹ 처음으로 / ⏩ 해까지. 키보드
  `Space` `→` `←` `Home` `End` 로도 됩니다.
- **위 — ⚖ 비교 · 📖 용어 · ? 도움말 · 가+/가− · 화면**: 성능 비교표, 용어 사전, 사용 안내,
  글자 크기, 밝게/어둡게.

### 용어를 다루는 방식

화면에는 교과서와 같은 정확한 용어(노드·상태·확장·OPEN 리스트·CLOSED·탐색 트리·휴리스틱)를
쓰고, 바로 옆에 쉬운 말을 덧붙였습니다. 평가 문항의 낱말과 화면의 낱말이 어긋나지 않게 하기 위함입니다.

## 4. 알고리즘별 수업 포인트

| 알고리즘 | 자료구조 | 학생이 발견할 것 |
|---|---|---|
| 너비 우선 (BFS) | 큐(FIFO) | 얕은 곳부터 훑어 **최단 경로**를 찾지만 OPEN이 크게 부푼다 |
| 깊이 우선 (DFS) | 스택(LIFO) | 한 갈래로 깊이 파고들어 8-퍼즐에서는 길을 잃는다 |
| 최상 우선 | 우선순위 큐(h) | 목표로 빠르게 돌진하지만 최단은 아니다 |
| A* | 우선순위 큐(f=g+h) | 조건을 갖추면 **빠르면서 최단** |
| 언덕 등반 | 현재 상태 | 더 나은 이웃으로만 가다 **지역 최적**에 막힌다 |

> 팁: **⚖ 비교** 화면을 띄우면 위 차이가 숫자로 한눈에 보입니다(깊이 제한·반복 심화도 여기 있음).
> 특히 **도전(31수)** 예제에서 깊이 우선은 포기하지만 A\*는 풀어냅니다.

---

## 5. 파이썬을 몰라도 되는 이유

학생이 코드를 **직접 타이핑하지 않습니다**. 대신 알고리즘 ④쪽에서 의사코드와 파이썬을
**나란히 놓고**, 한 단계 밟을 때마다 양쪽에서 같은 줄이 켜지고 그 줄이 판·OPEN을 어떻게
바꾸는지 함께 움직입니다. "이 의사코드 = 이 파이썬 = 이 화면 변화"를 눈으로 잇는 것이 목표입니다.
핵심 한 줄(꺼내는 자리·정렬 기준)만 드롭다운으로 바꿔 알고리즘이 달라지는 것을 실험합니다.

## 6. 자주 묻는 것

- **DFS로 바꾸니 금방 "포기"한다?** 8-퍼즐에서 스택 탐색은 원래 한 갈래로 끝없이 파고듭니다.
  그 모습을 짧게 보여 주려고 주 화면에서는 일부만 실행합니다. 난이도를 올리면 파고드는 길이도
  길어집니다. 정확한 규모는 **⚖ 비교** 화면에서 확인하세요.
- **글씨가 작다 / 교실 뒤에서 안 보인다** → 오른쪽 위 **가+** 버튼으로 키우세요.
- **눈이 부시다 / 어둡게** → **화면** 버튼으로 밝게·어둡게·자동을 바꿉니다.
- **모바일에서도 되나?** → 됩니다. 화면이 좁으면 세로로 접힙니다.

## 7. 과제 아이디어

1. 같은 초기 상태에서 BFS와 DFS의 **해의 길이**를 비교해 표로 정리하기.
2. A\*의 휴리스틱을 h0 → h1 → h2로 바꾸며 **펼친 노드 수**가 어떻게 줄어드는지 관찰하기.
3. 알고리즘 ④쪽에서 "핵심 한 줄"을 바꿔 보며, 왜 그 한 줄이 알고리즘을 정하는지 설명하기.
4. "도전" 예제를 여러 알고리즘으로 풀어 보고, **누가 풀고 누가 포기하는지** 발표하기.
