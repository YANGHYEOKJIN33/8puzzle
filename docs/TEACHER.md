# 교사용 안내 — 8-퍼즐로 배우는 탐색 알고리즘

이 사이트는 파이썬을 잘 모르는 **고등학생**이 인공지능 기초의 **탐색 알고리즘**을
순서도 → 의사코드 → 파이썬 순서로 배우도록 만든 것입니다. 설치·로그인 없이
주소 하나로 접속합니다.

> 사이트 주소: `https://yanghyeokjin33.github.io/Alg/`

---

## 1. 수업 예시

사이트는 맨 위 탭 두 개로 나뉩니다. **📦 자료구조(5쪽)** 와 **🧩 8-퍼즐 탐색(14쪽·3차시)** 입니다.
스택·큐를 배운 적 없는 학생이 많아 **자료구조 탭이 첫 화면**입니다. 두 탭 모두 한 쪽에
배울 것 하나만 담고, [다음 →] 을 누르며 진행합니다. 쪽마다 "📘 배울 것"(왜 배우는지
이유까지)과 "✋ 해 볼 것"이 적혀 있습니다. **한 화면에는 그 쪽에 꼭 필요한 것만** 켜지고,
자료구조와 탐색 트리처럼 둘을 견줄 때는 화면을 채우지 않고 **[자료구조 | 탐색 트리] 탭**으로
하나씩 봅니다.

### 자료구조를 안 배운 학급 — 준비 차시(📦 자료구조 탭, 약 45분)

먼저 자료구조 탭으로 큐·스택·우선순위 큐를 익힌 뒤, 아래 8-퍼즐 탐색 3차시로 넘어갑니다
(총 4차시). 이미 자료구조를 배운 학급은 이 준비 차시를 건너뛰어도 됩니다.

| 시간 | 탭·쪽 | 내용 |
|---|---|---|
| 0~10분 | 📦 1. 큐 | 매표소 줄 비유 → 넣기·꺼내기를 직접 눌러 본다 |
| 10~18분 | 📦 2. 스택 | 접시 더미 비유 → 같은 것을 넣어도 순서가 뒤집히는 것 |
| 18~26분 | 📦 3. 우선순위 큐 | 응급실 비유 → 나중에 와도 급하면 앞으로 |
| 26~35분 | 📦 4. 셋을 나란히 | 같은 입력, 다른 출력. "상자가 순서를 정한다" |
| 35~45분 | 📦 5. 잇기 | [이 탐색 보러 가기]로 8-퍼즐 탐색 탭으로 넘어간다 |

쪽마다 "다음에 꺼내면 무엇이 나올까요?" 맞히기가 있습니다. 맞힌 개수가 화면에
표시되니, 짝과 번갈아 맞혀 보게 하면 좋습니다.

### 8-퍼즐 탐색 — 3차시(각 45분) 예시

탐색 탭은 **개념을 잘게 나눈 14쪽**으로, 3차시에 걸쳐 진행합니다. 한 쪽에 배울 것 하나만
담고, 목표 문장 안에 **"왜 배우는지"** 를 함께 적었습니다.

**1차시 — 문제를 상태로 보고, 탐색의 재료를 안다 (1~5쪽)**

| 시간 | 레슨 쪽 | 내용 |
|---|---|---|
| 0~8분 | 1. 8-퍼즐과 상태 | **타일을 직접 밀어 보게** 하세요. 손으로 풀어 본 뒤라야 "상태·연산자"가 와닿습니다 |
| 8~16분 | 2. 상태공간과 탐색 | 한 상태의 **이웃 띠**를 보며 "그물처럼 이어진다 → 그래서 탐색이 필요하다"를 이야기 |
| 16~26분 | 3. 노드와 확장 | ⏭ 로 노드를 확장해 자식이 생기는 것을 확인. 빈칸 위치에 따라 자식이 2·3·4개 |
| 26~35분 | 4. OPEN | 자식이 생길 때 OPEN이 늘고(push), 꺼낼 때 주는(pop) 것을 관찰 (CLOSED는 다음 쪽) |
| 35~45분 | 5. CLOSED | **꺼낸 노드가 CLOSED 상자로 옮겨져 쌓이는 것**(방금 옮겨진 노드는 주황) — 왜 표시해 두는지 |

**2차시 — 자료구조 하나가 알고리즘을 정한다 (6~9쪽)**

각 쪽에 들어가면 알고리즘이 자동으로 바뀝니다(6쪽 BFS · 7쪽 DFS · 8쪽 A*). [탐색 트리]
탭으로 트리 모양을 견주면 차이가 한눈에 보입니다.

| 시간 | 레슨 쪽 | 내용 |
|---|---|---|
| 0~10분 | 6. 큐로 꺼내기 = BFS | 트리가 **층층이 넓게** 자라며 최단해를 찾는 것, OPEN이 크게 부푸는 것 |
| 10~20분 | 7. 스택으로 꺼내기 = DFS | 트리가 **한 줄로 깊게** 내려가며 헤매는 것을 BFS와 비교 |
| 20~32분 | 8. 평가값으로 꺼내기 = A* | OPEN 항목의 f 값, 확장 노드 수가 훨씬 적은 것 |
| 32~45분 | 9. 자료구조 바꿔 비교 | "OPEN 자료구조 ="를 바꿔 같은 퍼즐이 어떻게 달리 풀리는지 — 2차시의 핵심 한 문장 |

**3차시 — 순서도에서 코드로 (10~14쪽)**

| 시간 | 레슨 쪽 | 내용 |
|---|---|---|
| 0~10분 | 10. 순서도로 흐름 읽기 | 밟으면 활성 도형이 이동. 옆의 **"왜 이 모양인가"** 로 판단 두 개·되돌이 화살표의 뜻을 짚기 |
| 10~20분 | 11. 의사코드 한 줄씩 읽기 | 각 줄이 하는 일·이유를 한 줄씩. **"꺼내는 줄"이 알고리즘을 정한다**는 점에 주목 |
| 20~32분 | 12. 빈칸 채우기 | 앞에서 읽은 코드의 **딱 한 곳**(pop 자리 등)만 바꿔 알고리즘이 통째로 달라지는 것 |
| 32~42분 | 13. 파이썬으로 직접 작성 | 브라우저에서 진짜 파이썬 실행. 실행 뒤 ▶ 재생으로 찾은 경로를 다시 봅니다 |
| 42~45분 | 14. 오늘 배운 것 정리 | 낱말 정리 + "자료구조 → 알고리즘" 표. 표의 줄을 누르면 그 알고리즘으로 9쪽(비교)에 갑니다 |

11·12쪽이 잇닿아 있습니다. **11쪽에서 코드를 한 줄씩 읽어 "무슨 코드가 무슨 일을 하는지"**
를 먼저 익힌 다음, 12쪽에서 그 코드의 빈칸을 채웁니다. 12쪽에서는 **고른 값이 실제 퍼즐
배치 중 어느 것을 꺼내는지**를 진짜 배치로 보여 주고, 오른쪽 판 아래에 **"이 코드가 8-퍼즐에서
하는 일"** 짝짓기 표를 둡니다(`children(n)` → "빈칸을 상·하·좌·우로 밀어 만드는 새 배치들" 등).

## 2. 화면 구성 한눈에

화면은 탭과 레슨 쪽마다 필요한 것만 켜집니다.

**📦 자료구조 탭**

- **왼쪽 → 가운데 → 오른쪽**: 넣은 순서 → 자료구조 → 나온 순서로 흐릅니다.
- **가운데 그림**: 생김새가 곧 규칙입니다. 큐·우선순위 큐는 **양 끝이 뚫린 가로 관**,
  스택은 **위만 뚫린 세로 통**(옆과 바닥은 막혀 있음)으로 그립니다.
  파랑 = 다음에 나갈 것, 초록 = 방금 들어온 것, 주황 = 방금 나간 것
  (탐색 탭과 같은 색 뜻입니다).
- **우선순위 큐**: 항목마다 급한 번호가 붙고, 새로 넣은 것이 앞으로 끼어들면
  밀려난 것들이 잠깐 흔들리며 "앞의 n개를 제치고 끼어들었어요"라고 알려 줍니다.
  관 아래에는 "지금은 D가 4번으로 가장 급해요 → 다음에 나갑니다"가 늘 떠 있습니다.
- **맞히기**: 두 개 이상 들어 있으면 "다음에 꺼내면 무엇이 나올까요?"가 나옵니다.
  답을 고르면 이유를 알려 주고 실제로 꺼내 줍니다.
- **아래 — 넣기 · 꺼내기 · 비우기**: 쪽을 옮기면 상자는 자동으로 비워집니다.

**🧩 8-퍼즐 탐색 탭**

- **화면은 한 번에 하나만**: 한 쪽에는 그 쪽에 필요한 패널만 켜집니다. 순서도와 의사코드도
  나란히 쌓지 않고 **각각 다른 쪽**(10쪽 순서도 · 11쪽 의사코드)으로 나눠, 학생이 한 가지에
  집중하게 합니다.
- **퍼즐 판**: 지금 검사 중인 배치와 목표 배치를 나란히. 밀린 타일이 미끄러지며 강조됩니다.
- **[자료구조 | 탐색 트리] 탭**: 6~9쪽에서는 자료구조 패널 위에 이 탭이 있어, **한 번에 하나만**
  봅니다(기본=자료구조). 트리와 OPEN·CLOSED를 한 화면에 쌓지 않아 덜 복잡합니다.
- **대기 목록(OPEN)**: OPEN 리스트를 **자료구조 탭과 같은 관/통 그림**으로 그립니다 —
  큐·우선순위 큐는 왼쪽으로 넣고(push) 오른쪽으로 꺼내는(pop) 가로 관, 스택은
  오른쪽 한 곳에서 넣고 꺼내는 관(왼쪽은 막힌 바닥)입니다. 오른쪽 끝(다음에 나갈 노드)은
  파랑 "다음", 방금 넣은 노드는 초록으로 강조됩니다.
- **닫힌 목록(CLOSED)**: OPEN 바로 아래에 **CLOSED 상자**를 두어, OPEN에서 꺼내(pop)
  확장을 마친 노드가 어떻게 **CLOSED에 쌓이는지** 눈으로 보게 합니다(5쪽에서 처음 등장).
  방금 옮겨 온 노드는 주황("방금 닫힘")으로 강조되어 **OPEN → CLOSED 이동**의 순간이
  드러납니다. CLOSED는 집합(set)이라 순서가 없다는 것도 함께 짚어 줍니다. (깊이 제한·반복
  심화는 전역 CLOSED를 쓰지 않고 "지금 경로"만 확인하므로, 그 사실을 상자 자리에 대신 알려 줍니다.)
  카운터 4종(만든 모양·살펴본 모양·줄 최대 길이·지금 깊이)이 늘 보입니다.
- **순서도 '왜 이 모양'(10쪽)**: 순서도만 크게 보이고, 옆에 **도형별 이유**가 한 줄씩 붙습니다
  (판단 두 개·CLOSED·되돌이 화살표가 왜 그 자리에 있는지). 시작 도형에 `CLOSED ← ∅`가 함께
  적혀, 의사코드와 순서도가 정확히 1:1로 맞습니다.
- **의사코드 한 줄씩(11쪽)**: 코드 한 줄마다 **하는 일·이유**가 붙고, 밟으면 실행 중인 줄이
  파랗게 강조됩니다. 빈칸 채우기(12쪽) 전에 "무슨 코드가 무슨 일을 하는지"를 익히는 자리입니다.
- **맞히기(예측 퀴즈)**: OPEN이 두 개 이상일 때 자료구조 패널에 "다음에 꺼낼 노드는?"이
  떠, OPEN을 보며 FIFO/LIFO를 스스로 떠올리게 합니다.
- **동작 카드**: 지금 하는 일을 그림 + 한 문장(꺼내기 👆 / 넣기 📥 / 찾았다 🎉 …)으로 알려 줍니다.
- **위 — 실행 제어**: ▶ 재생 / ⏭ 한 단계 / ⏮ 뒤로 / ⏹ 처음으로 / ⏩ 해까지.
  학생이 바로 찾도록 화면 **위쪽**(레슨 막대 바로 아래)에 파란 띠로 둡니다.
  키보드 `Space` `→` `←` `Home` `End` 로도 됩니다.
- **위 — ⚖ 비교**: 같은 초기 상태로 여러 알고리즘의 성능을 표로 비교합니다.
  아래쪽 "📐 교과서 성질"을 펼치면 **완전성 · 최적성 · 시간 · 공간**을 함께 볼 수 있어,
  "이번에 잰 값"과 "언제나 성립하는 성질"을 구분해 설명할 수 있습니다.
- **위 — 📖 용어**: 화면에 나오는 용어 41개의 사전. 검색이 됩니다.
  수업 중 "이 말이 무슨 뜻이에요?"가 나오면 바로 띄워 주세요.
- **위 — ? 도움말**: 처음 사용법 안내를 다시 봅니다.

### 용어를 다루는 방식

화면에는 교과서와 같은 정확한 용어(노드 · 상태 · 확장 · OPEN 리스트 · CLOSED ·
탐색 트리 · 휴리스틱)를 쓰고, 바로 옆에 쉬운 말을 덧붙였습니다.
평가 문항의 낱말과 화면의 낱말이 어긋나지 않도록 하기 위함입니다.

## 3. 알고리즘별 수업 포인트

| 알고리즘 | 자료구조 | 학생이 발견할 것 |
|---|---|---|
| 너비 우선 (BFS) | 큐(FIFO) | 얕은 곳부터 훑어 **최단 경로**를 찾지만 OPEN이 크게 부푼다 |
| 깊이 우선 (DFS) | 스택(LIFO) | 한 갈래로 깊이 파고들어 8-퍼즐에서는 길을 잃는다(그래서 깊이 제한이 필요) |
| 깊이 제한 (DLS) | 스택 + 한계 | 한계가 작으면 못 찾고, 크면 헤맨다 |
| 반복적 깊이 심화 (IDS) | 스택 + 반복 | 한계를 1씩 늘려 **최단성 + 적은 메모리**를 함께 얻는다 |
| 언덕 등반 | 현재 상태 | 더 나은 이웃으로만 가다 **지역 최적**에 막힌다 |
| 최상 우선 | 우선순위 큐(h) | 목표로 빠르게 돌진하지만 최단은 아니다 |
| A* | 우선순위 큐(f=g+h) | 조건을 갖추면 **빠르면서 최단** |

> 팁: **⚖ 비교** 화면을 띄우면 위 차이가 숫자로 한눈에 보입니다.
> 특히 **도전(31수)** 예제에서 깊이 우선은 포기하지만 A\*는 풀어냅니다.

## 4. 세 가지 학습 단계

1. **의사코드** — 코드를 쓰지 않고 버튼만 눌러 흐름과 자료구조 변화를 관찰합니다.
   중간에 나오는 **예측 퀴즈**("다음에 꺼낼 노드는?")로 개념을 확인합니다.
2. **빈칸 채우기** — 거의 완성된 파이썬 코드에서 핵심 한 곳(`OPEN.pop(___)` 등)만
   드롭다운으로 채웁니다. `0`이면 너비 우선, `-1`이면 깊이 우선이 됩니다.
3. **직접 작성** — 파이썬 `search()` 함수를 직접 쓰고 **브라우저에서 실제로 실행**합니다.
   (처음 실행 때 파이썬 실행기를 한 번 내려받습니다 — 수십 초, 이후 빠름.)

각 단계는 자유롭게 오갈 수 있고, 단계를 바꿔도 고른 알고리즘·초기 상태는 유지됩니다.

## 5. 자주 묻는 것

- **DFS(스택)로 바꾸니 금방 "포기"한다?** 8-퍼즐에서 스택 탐색은 원래 한 갈래로
  끝없이 파고듭니다(전역 방문표를 쓰는 그래프 탐색 DFS는 얕은 문제도 못 찾고 헤맵니다).
  그 "파고드는" 모습을 짧게 보여 주려고 주 화면에서는 일부만 실행합니다. 난이도를
  올리면(목표가 더 깊을수록) **파고드는 길이를 조금 더 길게** 보여 주므로, 난이도를 바꾸면
  진행 횟수도 달라집니다. 정확한 규모는 **⚖ 비교** 화면에서 확인하세요.
