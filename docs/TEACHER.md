# 교사용 안내 — 8-퍼즐로 배우는 탐색 알고리즘

이 사이트는 파이썬을 잘 모르는 **고등학생**이 인공지능 기초의 **탐색 알고리즘**을
순서도 → 의사코드 → 파이썬 순서로 배우도록 만든 것입니다. 설치·로그인 없이
주소 하나로 접속합니다.

> 사이트 주소: `https://yanghyeokjin33.github.io/Alg/`

---

## 1. 수업 예시

사이트는 맨 위 탭 두 개로 나뉩니다. **📦 자료구조(5쪽)** 와 **🧩 8-퍼즐 탐색(8쪽)** 입니다.
스택·큐를 배운 적 없는 학생이 많아 **자료구조 탭이 첫 화면**입니다. 두 탭 모두 한 쪽에
배울 것 하나만 담고, [다음 →] 을 누르며 진행합니다. 쪽마다 "📘 배울 것"과
"✋ 해 볼 것"이 적혀 있습니다.

### 자료구조를 안 배운 학급 — 90분(2차시) 예시

| 시간 | 탭·쪽 | 내용 |
|---|---|---|
| 0~10분 | 📦 1. 큐 | 매표소 줄 비유 → 넣기·꺼내기를 직접 눌러 본다 |
| 10~18분 | 📦 2. 스택 | 접시 더미 비유 → 같은 것을 넣어도 순서가 뒤집히는 것 |
| 18~26분 | 📦 3. 우선순위 큐 | 응급실 비유 → 나중에 와도 급하면 앞으로 |
| 26~35분 | 📦 4. 셋을 나란히 | 같은 입력, 다른 출력. "상자가 순서를 정한다" |
| 35~45분 | 📦 5. 잇기 | [이 탐색 보러 가기]로 8-퍼즐 탐색 탭으로 넘어간다 |
| 45~90분 | 🧩 1~8쪽 | 아래 45분 예시 그대로 |

쪽마다 "다음에 꺼내면 무엇이 나올까요?" 맞히기가 있습니다. 맞힌 개수가 화면에
표시되니, 짝과 번갈아 맞혀 보게 하면 좋습니다.

### 8-퍼즐 탐색 45분 예시

| 시간 | 레슨 쪽 | 내용 |
|---|---|---|
| 0~6분 | 1. 8-퍼즐과 상태 | **타일을 직접 눌러 밀어 보게** 하세요. 손으로 풀어 본 뒤라야 "연산자"가 와닿습니다 |
| 6~12분 | 2. 노드를 "확장"해요 | ⏭ 한 단계를 누르며 동작 카드를 읽고, 아래 **자식 노드 띠**로 "확장(노드 하나에서 다음 배치 만들기)"을 확인. 빈칸 위치에 따라 자식이 2·3·4개 |
| 12~19분 | 3. OPEN 리스트와 CLOSED | OPEN이 늘고 주는 것, **꺼낸 노드가 CLOSED 상자에 쌓이는 것**(방금 닫힌 노드는 주황)을 관찰 |
| 19~29분 | 4. OPEN 자료구조를 바꿔 봐요 | 큐 ↔ 스택 ↔ 우선순위 큐로 바꾸며 **OPEN·CLOSED·탐색 트리가 함께 달라지는 것**을 한 화면에서 비교 |
| 29~35분 | 5. 순서도와 의사코드 | 순서도 전체·코드 줄·퍼즐 상태·**OPEN 리스트와 CLOSED**가 한꺼번에 바뀌는 것 |
| 35~42분 | 6~7. 빈칸 채우기 · 직접 작성 | 학생 실습. 실행 뒤 ▶ 재생으로 찾은 경로를 다시 볼 수 있습니다 |

6쪽에서는 **고른 값이 실제 퍼즐 배치 중 어느 것을 꺼내는지**를 초기 배치에서 만든
진짜 배치 세 개로 보여 주고(`pop(0)` ↔ `pop(-1)`, `n.h` ↔ `n.g+n.h`, `h` 세 가지 값),
오른쪽 퍼즐 판 아래에 **“이 코드가 8-퍼즐에서 하는 일”** 짝짓기 표를 둡니다
(`children(n)` → "빈칸을 상·하·좌·우로 밀어 만들 수 있는 새 배치들" 등).
"함수 이름만 보고는 무슨 일인지 모르겠다"는 지점을 여기서 짚어 주세요.
| 42~45분 | 8. 오늘 배운 것 정리 | 낱말 정리 + "자료구조 → 알고리즘" 표. 표의 줄을 누르면 그 알고리즘으로 4쪽에 갑니다 |

## 2. 화면 구성 한눈에

화면은 탭과 레슨 쪽마다 필요한 것만 켜집니다.

**📦 자료구조 탭**

- **왼쪽 → 가운데 → 오른쪽**: 넣은 순서 → 자료구조 → 나온 순서로 흐릅니다.
- **가운데 그림**: 생김새가 곧 규칙입니다. 큐·우선순위 큐는 **양 끝이 뚫린 가로 관**,
  스택은 **위만 뚫린 세로 통**(옆과 바닥은 막혀 있음)으로 그립니다.
  파랑 = 다음에 나갈 것, 초록 = 방금 들어온 것, 주황 = 방금 나간 것
  (탐색 탭과 같은 색 뜻입니다).
- **우선순위 큐**: 항목마다 급한 번호가 붙고, 새로 넣은 것이 앞으로 끼어들면
  밀려난 것들이 잠깐 흔들리며 "앞의 n개를 제치고 끼어들었어요"라고 알려 줍니다.
  관 아래에는 "지금은 D가 4번으로 가장 급해요 → 다음에 나갑니다"가 늘 떠 있습니다.
- **맞히기**: 두 개 이상 들어 있으면 "다음에 꺼내면 무엇이 나올까요?"가 나옵니다.
  답을 고르면 이유를 알려 주고 실제로 꺼내 줍니다.
- **아래 — 넣기 · 꺼내기 · 비우기**: 쪽을 옮기면 상자는 자동으로 비워집니다.

**🧩 8-퍼즐 탐색 탭**

- **순서도 · 코드**: 순서도와 의사코드를 **나란히** 두고, 실행 중인 도형과 줄을 함께 켭니다(탭 없음).
- **퍼즐 판**: 지금 검사 중인 배치와 목표 배치를 나란히. 밀린 타일이 미끄러지며 강조됩니다.
- **대기 목록(OPEN)**: OPEN 리스트를 **자료구조 탭과 같은 관/통 그림**으로 그립니다 —
  큐·우선순위 큐는 왼쪽으로 넣고(push) 오른쪽으로 꺼내는(pop) 가로 관, 스택은
  오른쪽 한 곳에서 넣고 꺼내는 관(왼쪽은 막힌 바닥)입니다. 오른쪽 끝(다음에 나갈 노드)은
  파랑 "다음", 방금 넣은 노드는 초록으로 강조됩니다.
- **닫힌 목록(CLOSED)**: OPEN 바로 아래에 **CLOSED 상자**를 두어, OPEN에서 꺼내(pop)
  확장을 마친 노드가 어떻게 **CLOSED에 쌓이는지** 눈으로 보게 합니다. 방금 옮겨 온 노드는
  주황("방금 닫힘")으로 강조되어 **OPEN → CLOSED 이동**의 순간이 드러납니다. CLOSED는
  집합(set)이라 순서가 없다는 것도 함께 짚어 줍니다. (깊이 제한·반복 심화는 전역 CLOSED를
  쓰지 않고 "지금 경로"만 확인하므로, 그 사실을 상자 자리에 대신 알려 줍니다.)
  그 아래에 탐색 트리를 함께 보여 줍니다.
  "줄 세우는 방법 =" 칩으로 큐·스택·우선순위 큐를 바꾸면 OPEN·CLOSED·트리가 어떻게
  달라지는지 바로 비교됩니다. 카운터 4종(만든 모양·살펴본 모양·줄 최대 길이·지금 깊이)이 늘 보입니다.
- **동작 카드**: 지금 하는 일을 그림 + 한 문장(꺼내기 👆 / 넣기 📥 / 찾았다 🎉 …)으로 알려 줍니다.
- **위 — 실행 제어**: ▶ 재생 / ⏭ 한 단계 / ⏮ 뒤로 / ⏹ 처음으로 / ⏩ 해까지.
  학생이 바로 찾도록 화면 **위쪽**(레슨 막대 바로 아래)에 파란 띠로 둡니다.
  키보드 `Space` `→` `←` `Home` `End` 로도 됩니다.
- **위 — ⚖ 비교**: 같은 초기 상태로 여러 알고리즘의 성능을 표로 비교합니다.
  아래쪽 "📐 교과서 성질"을 펼치면 **완전성 · 최적성 · 시간 · 공간**을 함께 볼 수 있어,
  "이번에 잰 값"과 "언제나 성립하는 성질"을 구분해 설명할 수 있습니다.
- **위 — 📖 용어**: 화면에 나오는 용어 41개의 사전. 검색이 됩니다.
  수업 중 "이 말이 무슨 뜻이에요?"가 나오면 바로 띄워 주세요.
- **위 — ? 도움말**: 처음 사용법 안내를 다시 봅니다.

### 용어를 다루는 방식

화면에는 교과서와 같은 정확한 용어(노드 · 상태 · 확장 · OPEN 리스트 · CLOSED ·
탐색 트리 · 휴리스틱)를 쓰고, 바로 옆에 쉬운 말을 덧붙였습니다.
평가 문항의 낱말과 화면의 낱말이 어긋나지 않도록 하기 위함입니다.

## 3. 알고리즘별 수업 포인트

| 알고리즘 | 자료구조 | 학생이 발견할 것 |
|---|---|---|
| 너비 우선 (BFS) | 큐(FIFO) | 얕은 곳부터 훑어 **최단 경로**를 찾지만 OPEN이 크게 부푼다 |
| 깊이 우선 (DFS) | 스택(LIFO) | 한 갈래로 깊이 파고들어 8-퍼즐에서는 길을 잃는다(그래서 깊이 제한이 필요) |
| 깊이 제한 (DLS) | 스택 + 한계 | 한계가 작으면 못 찾고, 크면 헤맨다 |
| 반복적 깊이 심화 (IDS) | 스택 + 반복 | 한계를 1씩 늘려 **최단성 + 적은 메모리**를 함께 얻는다 |
| 언덕 등반 | 현재 상태 | 더 나은 이웃으로만 가다 **지역 최적**에 막힌다 |
| 최상 우선 | 우선순위 큐(h) | 목표로 빠르게 돌진하지만 최단은 아니다 |
| A* | 우선순위 큐(f=g+h) | 조건을 갖추면 **빠르면서 최단** |

> 팁: **⚖ 비교** 화면을 띄우면 위 차이가 숫자로 한눈에 보입니다.
> 특히 **도전(31수)** 예제에서 깊이 우선은 포기하지만 A\*는 풀어냅니다.

## 4. 세 가지 학습 단계

1. **의사코드** — 코드를 쓰지 않고 버튼만 눌러 흐름과 자료구조 변화를 관찰합니다.
   중간에 나오는 **예측 퀴즈**("다음에 꺼낼 노드는?")로 개념을 확인합니다.
2. **빈칸 채우기** — 거의 완성된 파이썬 코드에서 핵심 한 곳(`OPEN.pop(___)` 등)만
   드롭다운으로 채웁니다. `0`이면 너비 우선, `-1`이면 깊이 우선이 됩니다.
3. **직접 작성** — 파이썬 `search()` 함수를 직접 쓰고 **브라우저에서 실제로 실행**합니다.
   (처음 실행 때 파이썬 실행기를 한 번 내려받습니다 — 수십 초, 이후 빠름.)

각 단계는 자유롭게 오갈 수 있고, 단계를 바꿔도 고른 알고리즘·초기 상태는 유지됩니다.

## 5. 자주 묻는 것

- **DFS(스택)로 바꾸니 금방 "포기"한다?** 8-퍼즐에서 스택 탐색은 원래 한 갈래로
  끝없이 파고듭니다(전역 방문표를 쓰는 그래프 탐색 DFS는 얕은 문제도 못 찾고 헤맵니다).
  그 "파고드는" 모습을 짧게 보여 주려고 주 화면에서는 일부만 실행합니다. 난이도를
  올리면(목표가 더 깊을수록) **파고드는 길이를 조금 더 길게** 보여 주므로, 난이도를 바꾸면
  진행 횟수도 달라집니다. 정확한 규모는 **⚖ 비교** 화면에서 확인하세요.
- **글씨가 작다 / 교실 뒤에서 안 보인다** → 오른쪽 위 **가+** 버튼으로 키우세요.
- **눈이 부시다 / 어둡게** → **화면** 버튼으로 밝게·어둡게·자동을 바꿉니다.
- **모바일에서도 되나?** → 됩니다. 화면이 좁으면 세로로 접힙니다.

## 6. 과제 아이디어

1. 같은 초기 상태에서 BFS와 DFS의 **해의 길이**를 비교해 표로 정리하기.
2. A\*의 휴리스틱을 h0 → h1 → h2로 바꾸며 **펼친 노드 수**가 어떻게 줄어드는지 관찰하기.
3. 학습 3단계에서 **깊이 우선 탐색**을 직접 구현해 보고, 왜 해가 길어지는지 설명하기.
4. "도전" 예제를 여러 알고리즘으로 풀어 보고, **누가 풀고 누가 포기하는지** 발표하기.
